# StoryNest — ITE 1 Storybook Project

A responsive Wattpad-inspired story library with 30 original, single-chapter stories.

## How to run
1. Extract the ZIP folder.
2. Open `index.html` in a browser. For best results, use VS Code with the Live Server extension.
3. Click **Read story** on any card. Each opens `story.html?id=...` and loads the matching story.
4. No build tools or server are required.

## Files
- `index.html` — story library and working navigation
- `story.html` — single-chapter reading template; each story has its own URL
- `style.css` — one external stylesheet
- `stories.js` — one external JavaScript file containing story data and interactions
- `stories.json` — readable copy of story data
- `images/` — 30 original SVG book covers and 30 supporting story illustrations

## JavaScript features
- Dark/light mode (preference saved in localStorage)
- Like buttons (saved in localStorage)
- Show/hide synopsis
- Search and genre filtering, plus title sorting
- Reading progress indicator

## Requirement checklist
- 30 different book covers and genres: included
- One chapter per book: included
- Semantic `header`, `nav`, `main`, `section`, `article`, and `footer`: included
- One external CSS file and one external JS file: included
- Responsive layout, cards, hover effects, spacing, shadows, and readable reading view: included
- At least 5 cover images and one supporting image per story: included locally in `images/`
- Working navigation and corresponding Read Story links: included
